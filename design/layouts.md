# 页面布局说明（Layouts）

> 栅格：桌面端内容宽 1280px，12 列，间距 24px；`lg`（1024px）以下折叠成单栏，`md`（768px）以下进入移动布局。
> 效果图在 `screenshots/`，可交互原型在 `prototype/`（每个页面的类名与本文档一致）。
> 现有路由保持不变：`/`、`/goods/:id`、`/publish`、`/chat`、`/user`、`/admin/*`。只改视觉和组件结构，不改接口调用。

---

## 公共框架

### 用户端布局 `UserLayout.vue`

```
┌──────────────────────────── app-header（68px，sticky，玻璃拟态）───────────────────────────┐
│ [Logo 渐变方块+校园闲置]  发现 分类 消息 我的   [  搜索框（胶囊，聚焦时变宽）  /]  [+发布闲置] 🔔 ☾ (头像) │
└────────────────────────────────────────────────────────────────────────────────────────────┘
  body::before：顶部 900px 网格渐变氛围背景（向下渐隐）
  <router-view> + 页面切换动画（motion.md §1）
  footer
```

- **关键组件**：`AppHeader`（新）、`ThemeToggle`（新）、`el-badge`（未读数，数据来自 `chatStore.unreadTotal`）、头像下拉 `el-dropdown`（个人中心 / 我的订单 / 管理后台 / 退出）。
- **响应式**：`<1024` 隐藏文字导航；`<768` 隐藏顶部搜索框，改成搜索图标打开全屏搜索层，同时底部出现 5 栏 **TabBar**（首页 / 分类 / 发布〔居中凸起的渐变圆钮〕/ 消息 / 我的），高 64px，同样是玻璃拟态。
- **未登录**：头像位置换成「登录」文字按钮 +「注册」胶囊按钮；点击发布或消息时跳转登录页（沿用现有路由守卫）。

### 管理端布局 `AdminLayout.vue`

`grid-template-columns: 248px 1fr`，左边是玻璃侧栏（Logo、分组菜单「概览 / 管理」、当前项用品牌渐变填充、待办数用珊瑚色徽章、底部是管理员卡片和「返回前台」），右边是 72px 高的吸顶 topbar（面包屑 + 页面标题、全局搜索 ⌘K、时间范围分段控件、通知、暗色切换），内容区内边距 28px 32px。`<1024` 时侧栏收起成 72px 宽的纯图标栏，hover 时展开。

| 模块 | 数据来源 | 关键组件 |
| --- | --- | --- |
| Hero 搜索 | 跳转 `/search?keyword=&categoryId=` | `el-input`（`.ct-search`）+ `el-select` 分类 |
| 统计数字 | 可选：后台概览接口；拿不到时隐藏整行 | `useTransition` 数字滚动 |

- **加载态**：推荐区和列表首屏显示与卡片同尺寸的骨架（4 张）；Hero 统计数字显示 `—`。

- **异常**：接口失败时在区块内显示「加载失败，点击重试」，不弹全局错误。

- **关键组件**：`SessionList`（`el-scrollbar`，按最后一条消息时间倒序，未读数用珊瑚色徽章）、`MessageList`（`TransitionGroup`，滚动到顶部加载更早消息）、`MessageBubble`（type 1 文本 / 2 图片〔`el-image` 预览〕/ 3 商品卡）、`Composer`（Enter 发送、Shift+Enter 换行，图片上传复用文件接口）、`PinnedGoods`（从会话的 goodsId 获取商品信息）。实时消息沿用现有 `chatStore` + STOMP（`/app/chat.send`、`/user/queue/messages`、`/user/queue/read`）。

- **空状态**：没有任何会话时，中间显示插画（两个对话气泡）+「还没有消息，去看看感兴趣的闲置吧」+「去逛逛」；有会话但没选中时，主区域显示「选择一个会话开始聊天」。
- **加载态**：会话列表显示 6 条骨架（圆形头像 + 两行文字）；切换会话时消息区先显示 3 个左右交替的骨架气泡；加载更早消息时顶部显示小 spinner。
- **连接状态**：STOMP 断开时在头部下方显示一条黄色细条「连接已断开，正在重连…」，重连成功后变绿并在 1.5s 后收起。

- **关键组件**：`KpiCard`、ECharts 折线 / 环形图（复用现有 `useChart`，配色见 design-system §8）、`el-table`（主题已覆盖为圆角表头、行 hover 浅紫）、`el-segmented`、`el-popconfirm`（驳回时必须填写原因，用 `ElMessageBox.prompt`）。
- **子页统一模板**（审核中心 / 用户管理 / 商品管理 / 举报处理 / 公告管理）：顶部筛选栏（搜索 + 状态 Chip + 日期范围），下面是白色卡片包裹的表格，分页在右下角；批量操作出现时，表格上方滑出一条操作栏（已选 N 项 · 批量通过 · 批量驳回）。审核中心用左边列表、右边详情的双栏（右侧显示图片、描述、卖家信誉和历史违规），支持键盘 J/K 切换、A 通过、R 驳回。
- **用户行为分布**：直接对应方案 5.3 节 `user_behavior` 的四种行为和 1/3/4/5 权重，答辩时可以用来讲推荐数据的来源（数字以真实统计为准）。
- **响应式**：`<1280` KPI 改为 2×2，图表行变成上下排列；`<1024` 侧栏收起成图标栏；表格横向滚动，第一列和操作列固定（`fixed`）。
- **空状态**：待审核为 0 时显示插画「全部处理完了 🎉」；图表没有数据时显示 `el-empty`（小尺寸）+「所选时间范围内暂无数据」。
- **加载态**：KPI 数字骨架 + 图表区域的 shimmer 块；表格使用 `v-loading`（遮罩已改为毛玻璃）。
